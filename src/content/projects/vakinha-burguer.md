# Vakinha Burguer

![Capa do projeto](https://github.com/welitonsousa/vakinha_burguer/blob/main/assets/images/logo.png?raw=true)

## Apresentação

App de delivery

## Contexto

Este projeto representa uma solução desenvolvida com foco em qualidade técnica, experiência do usuário e escalabilidade. Durante sua construção foram aplicados conceitos modernos de arquitetura de software, organização de código e desenvolvimento multiplataforma, permitindo a entrega de uma aplicação consistente e preparada para evolução contínua.

## Desenvolvimento

Nesta aplicação, foram obtidos diversos conhecimentos novos, com uma poderosa aplicação de montagem de uma carrinho de comida, com pagamento via PIX

Aplicativo de delivery desenvolvido para aprendizado de arquitetura limpa junto com o GETX, um poderoso sistema de injeção de dependências
